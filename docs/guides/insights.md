# Collection insights

![Collection insights: makers, materials, dimensions, and data completeness](../images/insights.png)

Insights answer questions about the collection as a whole rather than one knife at a time: which makers you actually collect, how materials and dimensions are distributed, how complete your records are, and how much activity the collection has seen.

## What you can read from it

- **Makers** — where the collection is concentrated, and which makers are represented by a single piece.
- **Materials and dimensions** — blade steels, handle materials, and size ranges across the collection.
- **Completeness** — where records are missing data, which is the shortest path to a better catalog.
- **Activity** — additions and maintenance over time.

## Drilling in

Chart details can be opened to inspect the **matching knives** behind a number, so an insight is a starting point rather than a dead end. **Print Report** opens the Overview for printing or saving as a PDF.
