# Compare knives

![A saved comparison list with specifications shown side by side](../images/compare.png)

## Named shortlists

Comparisons are saved as **named lists**. A knife can belong to several lists, so "next purchase", "EDC rotation" and "gift ideas" can each hold overlapping candidates.

## Showing only the differences

Two similar knives often differ in one dimension or one steel. **Show only differences** hides the fields where the knives agree, so the decision is about what actually differs.

## Print and export

Comparisons can be printed or exported as **PDF**, which is handy for taking a shortlist to a shop, a knife show, or a conversation with a maker.

## Backups and upgrades

Saved comparisons are included in full-vault backups and in [cloud backups](../reference/cloud-backup.md). Changing a comparison list does not trigger an automatic cloud backup by itself. When upgrading from before v1.2.0, the old comparison selection becomes **My comparison**.
