Proposal · Modern style refresh

Less Apple Settings. More forged steel.

Today's Modern is a token swap to system blue on grey, so it reads plain and could belong to any app. This proposal keeps the layout but changes the material: graphite surfaces, lit image wells that make each knife look like a product shot, mono numerals for specs, one strong accent, and a new mark. Pick a direction and mode above. Every mock on this page follows your choice.

Implementation sketch (Modern only, Classic and Alloy untouched)
  • Replace the html[data-theme-style='modern'] and .dark token blocks in app/globals.css with the chosen palette. Add --accent-grad, --well, and --glow tokens.
  • Load Geist and Geist Mono for Modern only, and apply mono plus tabular-nums to spec values, counts, and stats.
  • Make dark the default for Modern. Light stays fully supported.
  • Scoped Modern styles for knife cards: lit image well, 3-column spec grid, and hover glow. No layout or behavior changes.
  • Sidebar: active row with a gradient edge bar, mono counts, and a backup status footer. Same links and actions.
  • New logo as an inline SVG using currentColor plus the accent token, replacing public/logo.svg, logo-dark.svg, app/icon.svg, and the app icons (a separate step if you want it).
